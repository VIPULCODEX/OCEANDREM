Methodology & Data Sources

ARGO Floats

Sparse in-situ subsurface temperature/salinity profiles. Real pipeline hook uses argopy.DataFetcher().region([...]) — see get_argo_data().

MOSDAC / ISRO + CMEMS

Real, live in this build (see Live Data section above): INSAT-3DR L2B SST (ISRO/SAC, 25 Aug 2026) and CMEMS thetao + so (SST & SSS) reanalysis (Aug 2026), baked into public/data_real.json.

NASA Worldview / GIBS

VIIRS / MODIS / GOES true-color imagery for visual context and coastline/eddy sanity-checking alongside the numeric SST grid.

Adaptive Clustering

Loo et al. 2026, arXiv:2605.00860 — spatiotemporal clustering to group profiles sharing thermocline structure before reconstruction; approximated here with a lightweight KMeans over (lat, lon, day, SSH).
