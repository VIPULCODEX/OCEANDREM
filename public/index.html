The Pipeline, in Four Steps

  1. Collect — real satellite surface data (temperature, salinity, currents, chlorophyll) + sparse underwater float readings.
  2. Train — a neural network learns to map surface patterns to underwater temperature.
  3. Test — check the guess against floats the network never saw.
  4. Monitor — watch for warming events (heatwaves) as new data comes in.
